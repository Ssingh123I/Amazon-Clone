# Amazon Clone

A simple Amazon-style homepage clone built with HTML, CSS, and JavaScript.

## Features

- Search input with toast notification behavior
- Product cards with clickable detail modal
- Add to cart buttons for each product tile
- Cart item count badge updates dynamically
- Back to top button in footer
- Toast messages for actions and alerts

## Files

- `index.html` — main page structure
- `style.css` — visual layout and styling
- `script.js` — interactive behavior and event handling

## Usage

1. Open `index.html` in a web browser.
2. Use the search bar and click the search icon to see a toast notification.
3. Click any product card to open its modal.
4. Use the Add to cart buttons to increment the cart count.
5. Click the footer section "Back to top" to scroll smoothly to the top.

## Notes

- The project uses a local `script.js` file for JavaScript functionality.
- Images are referenced by name in the CSS and HTML; replace with actual image files if needed.
